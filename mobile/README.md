# Dealzora سلسلة — تطبيق الهاتف

تطبيق المالك ومديري الفروع لمتابعة كل فروع المحل (خطة «سلسلة» فقط). Expo SDK 58 + TypeScript strict،
عربي RTL بالكامل، وضع داكن. يتصل **بخادم المزامنة فقط** (`/mobile/v1`) ولا يتصل بأجهزة الفروع أبداً.

## الهيكل

```
src/
  app/                  المسارات فقط (expo-router): الدخول، الترقية، حسابي، والتبويبات الخمسة
  api/                  عميل API واحد: التوكن والتجديد (single-flight)، الأخطاء بالعربي، انقطاع الإنترنت
  features/
    auth/               الدخول، الجلسة، التوكنات في SecureStore
    lock/               القفل بالبصمة/الوجه (عند الفتح وبعد دقيقة في الخلفية، قابل للإيقاف)
    account/            حسابي: الأجهزة، الخروج، الخروج من كل الأجهزة
    branches/           الفروع المسموحة و«آخر اتصال من الفرع»
    plan/               شاشة «الخطة لا تدعم التطبيق»
  components/shared/    مكوّنات الواجهة (نص، زر، حقل، بطاقة، شريط «بلا إنترنت»، آخر تحديث…)
  hooks/ lib/ theme/    الاتصال، التنسيق، TanStack Query مع الحفظ، الألوان والخط و RTL
```

- **الأسرار**: التوكنات ومعرّف الهاتف في SecureStore فقط. بيانات العرض المحفوظة (AsyncStorage) لا تحتوي أي توكن،
  وتُمسح عند الخروج. ESLint يمنع `console.log`.
- **بلا إنترنت**: آخر بيانات محفوظة تُعرض مع «آخر تحديث» وشريط واضح، وتتحدث تلقائياً عند رجوع الاتصال.
- **المال** بالقروش (integer)، والتنسيق في العرض فقط (`lib/format.ts`).

## الأوامر

```bash
npm install
npm run typecheck     # tsc --noEmit
npm run lint          # expo lint
npm test              # jest (عميل الـ API والتنسيق)
npm start             # خادم التطوير (Expo)
```

## التشغيل على هاتفك (خطوة بخطوة)

### 1) شغّل خادم المزامنة بحيث يراه الهاتف
الهاتف والكمبيوتر على **نفس شبكة الواي فاي**. من مجلد `sync-server`:

```bash
# Windows (PowerShell): مرة واحدة لكل نافذة
$env:SYNC_JWT_SECRET = "<32+ حرف>"; $env:SYNC_ADMIN_TOKEN = "<32+ حرف>"
.venv/Scripts/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

`--host 0.0.0.0` ضروري (الافتراضي 127.0.0.1 لا يراه الهاتف). اعرف IP جهازك بـ `ipconfig`
(مثلاً `192.168.1.10`) واسمح لبايثون في جدار حماية ويندوز عند السؤال.
جرّب من متصفح الهاتف: `http://192.168.1.10:8000/health` يجب أن يرد `{"status":"ok"}`.

> على الخادم الحقيقي (VPS بـ HTTPS) اكتب عنوانه مباشرة بدل كل هذا.

### 2) جهّز حساباً وكود ربط
التطبيق يدخل بحساب **المالك أو مدير فرع** الموجود في البرنامج المكتبي (نفس اسم المستخدم وكلمة المرور)،
والمحل لازم يكون مربوطاً بالخادم وعلى خطة «سلسلة». ثم اطلب كود ربط هاتف (صالح 15 دقيقة، مرة واحدة):

```bash
.venv/Scripts/python -m app.cli list                    # يعرض shop_id لكل محل
.venv/Scripts/python -m app.cli mobile-code <shop_id>   # كود ربط الهاتف: XXXX-XXXX-XXXX
```

(أو من أي جهاز فرع عبر `POST /v1/shop/mobile-code`؛ شاشة ذلك في البرنامج المكتبي لم تُبنَ بعد.)

### 3) شغّل التطبيق

**الأسرع — Expo Go (بدون بناء):**
1. ثبّت **Expo Go** من Google Play / App Store (الإصدار الداعم لـ SDK 58).
2. من مجلد `mobile`: `npm install` ثم `npx expo start`.
3. أندرويد: امسح رمز QR من داخل Expo Go. آيفون: امسحه بالكاميرا.
   لو الهاتف لا يصل للكمبيوتر (شبكة شركة/عزل عملاء): `npx expo start --tunnel`.
4. في شاشة الدخول: عنوان الخادم `http://192.168.1.10:8000`، ثم الكود، واسم المستخدم، وكلمة المرور.

حدود Expo Go: Face ID على آيفون لا يعمل داخله (البصمة على أندرويد تعمل)، و RTL الكامل للنظام
(اتجاه الإيماءات والعناوين الأصلية) يسري بعد إغلاق التطبيق وفتحه مرة. الواجهة نفسها RTL من أول فتح.

**بناء تطوير (development build) — كل شيء يعمل كما في النسخة النهائية:**
```bash
npx expo install expo-dev-client
npx eas-cli@latest build --profile development --platform android   # يبني في السحابة، ثبّت الـ APK الناتج
npx expo start                                                        # ثم افتح التطبيق المثبّت
```
أو محلياً لو عندك Android Studio: `npx expo run:android` (مع هاتف موصول بـ USB debugging أو محاكي).

### المحاكي (Android Emulator)
ثبّت Android Studio وأنشئ جهازاً افتراضياً، ثم `npx expo start` واضغط `a`.
عنوان الخادم من داخل المحاكي: `http://10.0.2.2:8000` (هو الكمبيوتر نفسه).

## مشاكل شائعة

| العرض | الحل |
|---|---|
| «لا يوجد اتصال بالإنترنت» عند الدخول | الخادم ليس على `0.0.0.0`، أو جدار الحماية، أو الهاتف على شبكة أخرى. جرّب `/health` من متصفح الهاتف |
| «كود ربط الهاتف غير صحيح» | الكود صالح 15 دقيقة ومرة واحدة، ويُبطَل بعد 5 كلمات مرور خاطئة. اطلب كوداً جديداً |
| «اسم المستخدم أو كلمة المرور غير صحيحة» | الحساب لازم يكون قد وصل للخادم مع مزامنة البرنامج (المالك أو مدير، لا كاشير) |
| شاشة «التطبيق متاح في خطة سلسلة فقط» | رقِّ خطة المحل من البرنامج، ثم «تحقّق مرة أخرى» |
